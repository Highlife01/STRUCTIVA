# STRUCTIVA Website Prototype

Premium global steel structures website prototype created for Ark Çelik rebranding.

## Run

```bash
pnpm install
pnpm dev
```

The production build is available with `pnpm build`.

## Included

- Responsive React + Tailwind frontend
- STRUCTIVA visual identity
- Hero, solutions, sectors, engineering, projects and quote sections
- Multilingual selector prototype
- Project brief form interaction
- Original visual concept assets in `assets/`

## Notes

The contact form is currently frontend-only. Replace placeholder contact details and connect the form to the preferred CRM or backend before production launch. Technical claims marked with an asterisk should be validated against current certificates, contracts and market requirements.
